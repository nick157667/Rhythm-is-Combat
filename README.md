# 專題簡介
《Rhythm is Combat》 是一款結合 AI 音樂生成與節奏判定射擊系統的 3D 第一人稱射擊遊戲。遊戲透過 Stable Audio 1.0 根據玩家輸入提示詞自動產生音樂，並以 BurstFFT 分析音樂節奏資訊，生成節奏圖譜（beatmap）。敵人會正常出現，但玩家必須跟著節奏射擊，才能成功造成傷害或得分。
